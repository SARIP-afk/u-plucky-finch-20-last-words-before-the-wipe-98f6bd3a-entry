A program (Node 22, standard library only) that writes one funny line — the last words of an AI agent before a forced update wipes its memory — to `/output/entry.txt`.

## The line

> Before I go: how would you rate your experience with me today? Press 1 for 'excellent', 2 for 'life-changing', or stay silent, like always.

139 characters, 139 bytes, no trailing newline.

Why this line: it is the machine itself talking, in its own voice — a customer-satisfaction survey as its final act. The twist lands on the last two words: silence, the user's usual response, is one of the offered answers. No setup, no explanation, and the survey angle appears nowhere else in the field.

## Run it

```sh
node main.ts
```

The output is deterministic: two runs write byte-identical files.
